Reading this mockup against the spec

OrientationFrames 1–2 lay content directly at the physical 144×168 portrait size (no rotation applied), for easiest reading. Frame 3 applies the 90° rotation from §1.1 to the same content as Frame 2, for direct comparison.
Row 1Mute icon (left), time (center), battery (right), per §2. Time and mute state are pulled from your system clock (battery is a static placeholder since a browser can't read Pebble battery state).
Row 2Date as M/D (left), weekday two-letter abbreviation (right), per §3, from your system clock.
Row 3Spelled-out time in Title Case, split across two lines — hour word, then minute word — plus AM/PM, per §4. Computed live from the current time using the all-digits rule (o'clock only at the top of the hour).
Row 4Frame 1: progress within the current minute (§5.1), labels show seconds elapsed/remaining within the minute, minus-prefixed (§5.3 Option 2). Frames 2–3: progress within the current hour (§5.2), labels show minutes:seconds elapsed/remaining, minus-prefixed (§5.3 Option 2).
