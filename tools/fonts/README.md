# Fonts

`Carthage-Sans-Bold.ttf` is Carthage Sans Bold by Brian Connors, from
https://github.com/csyde/carthage-fonts, used under the SIL Open Font License
1.1 (see `OFL.txt`). It is only used at build time by `tools/gen_assets.py`;
the watch face ships the rendered sprite sheets, not the font file.
