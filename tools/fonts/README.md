# Fonts

`Carthage-Sans-Bold.ttf` is Carthage Sans Bold by Brian Connors, from
https://github.com/csyde/carthage-fonts. `CARTHAGE_LICENSE.txt` and
`CARTHAGE_README.md` are the font's own license and readme, kept unmodified
as distributed upstream (the project uses the font under the SIL Open Font
License 1.1, one of its two licenses). The font is only used at build time by
`tools/gen_assets.py`; the watch face ships the rendered sprite sheets, not
the font file.
